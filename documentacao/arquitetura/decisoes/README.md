# Decisões de arquitetura

Registre aqui uma decisão apenas depois de confirmar os dados externos e a
alternativa escolhida. As pendências atuais estão em
[`decisoes-pendentes.md`](../../pendencias/decisoes-pendentes.md).

Para cada decisão, copie `TEMPLATE.md` para um arquivo numerado, por exemplo
`001-mapa-clp.md`. Preencha a fonte da informação, a consequência operacional
e a validação exigida antes de marcar o status como **Aceita**. Uma mudança
posterior deve criar outro registro e indicar qual decisão substitui.

Não use um registro de decisão como substituto da homologação em bancada do
CLP, do scanner ou da câmera.
